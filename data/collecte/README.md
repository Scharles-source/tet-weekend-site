# Dossiers de collecte

Un dossier par restaurant (`<slug>/`) :

- `collecte.json` — sources + lignes proposées / vérifiées
- `sources/` — images, HTML, PDF, texte OCR (les binaires images/PDF sont gitignorés)
- `PISTES.md` — pistes Instagram / site déjà connues (fouille du 15 oct. 2026)

`ETAT.md` est régénéré par `npm run collecte:etat`.

Voir le README racine, section **Collecte des menus**.
